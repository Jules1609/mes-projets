Voici les fichiers présents dans le répertoire du projet :

- 8 fichiers .npy contenant des données pré-calculées pour gagner du temps lors de l'exécution du programme.
- Fichier audioTrain4.mp3 utilisé pour récupérer les fréquences sonores émises par le train en circulation.
- Fichier audio.py contenant les fonctions nécessaires pour le traitement du signal audio.
- Fichier compute_alpha.py contenant la fonction de calcul du paramètre alpha pour notre algorithme et qui permet également de comparer les performances des différents matériaux.
- Fichier prepocessing.py contenant les fonctions de pré-traitement pour notre algorithme.
- Fichier prepocessing_avec_nouveaux_fractals.py contenant les fonctions de pré-traitement avec les nouveaux fractals codés (nous n'utilisons pas ce fichier dans le code principal).
- Fichier processing.py contenant les fonctions de traitement principal pour notre algorithme.
- Fichier postprocessing.py contenant les fonctions de post-traitement pour tracer les résultats notamment.
- Fichier demo_control_polycopie_cas_simple.py qui permet de lancer l'optimisation dans un cas simple comme décrit dans notre rapport.
- Fichier demo_control_polycopie_version_complete.py qui permet de lancer l'optimisation dans le cas complet (avec la source étudiée et l'optimisation sur 2 fréquences) comme décrit dans notre rapport.


Pour observer les résultats, il suffit de lancer les scripts demo_control_polycopie_cas_simple.py ou demo_control_polycopie_version_complete.py selon le cas que l'on souhaite étudier.
